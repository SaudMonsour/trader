# مشروع وكيل تداول الأسهم

يحتوي هذا المستودع على مشروع تداول وتحليل أسهم منظم داخل مجلد `QuantumEdge/`.

[قراءة التعريف العربي الكامل](QuantumEdge/README.md)

يعمل الإعداد الافتراضي في وضع التداول التجريبي. يتضمن المشروع وحدات البيانات والاستراتيجيات وإدارة المخاطر والتنفيذ والتتبع ولوحة المتابعة. تشغيل التداول الحقيقي يحتاج إلى إعداد صريح؛ هذا التحديث يعرّب التوثيق فقط.
