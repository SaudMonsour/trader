# وكيل تداول الأسهم

نظام معياري لتداول الأسهم الأمريكية، يربط تحليل السوق والاستراتيجيات وإدارة المخاطر والتنفيذ ولوحة المتابعة.

## الوظائف
- مؤشرات فنية تشمل الزخم والمتوسطات والتذبذب وحجم التداول.
- استراتيجيات اختراق الزخم والعودة إلى المتوسط واتباع الاتجاه.
- تقييم الإشارات بغابة عشوائية، مع دعم إعادة التدريب.
- تتبع الأداء والأوامر في SQLite، ولوحة Streamlit.
- حدود للخسارة اليومية وحجم المركز وعدد المراكز، وإيقاف التداول وفق ظروف الخطر.

الإعداد الافتراضي هو التداول التجريبي عبر Alpaca. التداول الحقيقي يحتاج إلى مفاتيحه وعنوانه وتفعيل صريح؛ قد يعرّض رأس المال للخسارة.

## التنظيم والتشغيل
المكونات والاختبارات داخل `QuantumEdge/`. تُفصل إدارة البيانات والمخاطر والاستراتيجيات والتنفيذ والتتبع. يحتاج التنفيذ إلى تهيئة حساب الوسيط وملف البيئة. تشغيل النظام أو جدولة أوامره ليس جزءًا من تعريب هذا التوثيق.

## الضوابط الموثّقة
حد الخسارة اليومية 2%، وحد المركز 5%، وبحد أقصى ثلاثة مراكز متزامنة. يوقف النظام العمل عند تجاوز مؤشر التقلب 30، ويتجنب أول وآخر 15 دقيقة، ويصف تصفية يومية عند 3:45 مساءً بالتوقيت الشرقي الأمريكي.

توجد مهام لفحص السوق كل خمس دقائق، وفحص المخاطر كل دقيقة، وتقرير أداء عند 4:30 مساءً، وإعادة تدريب أسبوعية. تحتاج هذه المهام إلى عملية تشغيل فعلية.

## المرجع
هذا برنامج تجريبي وتحليلي، ولا يضمن نتائج استثمارية. تفاصيل الضبط والأوامر والاختبارات محفوظة في [النسخة التقنية](README.en.md).
